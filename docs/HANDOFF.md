## 最小迁移范围

复制需要的 HTML 入口、`src/`、`assets/white/`、`vendor/rigby2d/`，保持相对目录即可运行。保留第三方许可与 THIRD_PARTY_NOTICES.md。若需要重新标定，再复制 `assets/source-layers/`、绑定生成器和 tools。无需 work、本地备份、原图或 PSD；无 npm 依赖与构建步骤。

运行 `node tools/dev-server.mjs`，浏览器打开 http://127.0.0.1:8768/ 。观看者只需 Chromium。开发服务仅用于本地，不应直接作为生产服务。

## 接入其他项目

1. 先以独立容器或同源 iframe 接入所需页面，核对路径及画布尺寸。
2. 当前每个入口有自己的播放循环与确定性时间轴；正式组件化时抽取加载、播放、暂停、seek、挂点和销毁接口。不要同时加载多个隐藏演示持续运行。
3. 后续对话状态只负责触发动作；增加打断/恢复、最短展示时长、资源生命周期，再接大模型及语音。当前没有大模型接口或业务后端。
4. 画布坐标 1000×570，人物世界纵轴向上；桌椅/道具层与人物层要共用坐标换算。
5. 换图需要重新标定关节、裙装腰线与手掌偏移。当前不是通用自动绑定。

## 已知边界

二维伪侧面、网格衣服变形、手工褶皱和接触提示；不是真实布料/刚体模拟。头发目前跟随头部，飞行拖曳尚未实现；手掌没有逐指绑定。完整聊天页面的性能、生产部署及真实侧身未验收。已有形象用于技术验证，正式产品需使用权利明确的素材。
