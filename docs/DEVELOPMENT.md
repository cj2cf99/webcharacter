# WebCharacter 开发指南

当前基线：2026-11-01，Rigby2D 可行性验证已获用户接受；进入动作规范及细化阶段。旧 iki 结论见 `history/FEASIBILITY-2026-11-01.md`，不再作为主路线。

## 1. 目标与约束

将两个参数驱动的小角色嵌入对话主题网页，进行简单角色扮演。免费、Chrome/Edge、低负载、观看者不安装软件。开发采用已有 Node.js 24；无 npm 安装和构建。当前不接大模型或语音。

## 2. 当前架构

- `rigby-validation.html` / `src/rigby-demo.mjs`：双角色苹果交互。
- `src/rigby-scene.mjs`：12 秒确定性时间轴。
- `src/rigby-actor.mjs`：实例化骨骼、伪侧面小步、手脚 IK、手掌和嘴部挂点。
- `rigby-magic.html` / `src/rigby-magic.mjs`：24 秒魔法小剧场、前后道具画布和角色 WebGL 画布。
- `src/rigby-magic-scene.mjs`：拾取、收纳、临时绘制顺序、侧坐、飞行。
- `src/rigby-seated-dress.mjs`：腰线下局部网格形变，三个参数微调。
- `src/rigby-white-build.mjs`：从已整理拆层生成 23 根骨骼、4 个 IK 约束和 16 张裁片。
- `assets/white/`：运行资源，纳入 Git；`assets/source-layers/`：绑定输入，纳入 Git。
- `vendor/rigby2d/`：固定提交的未修改引擎，离线加载，无上游示例角色。

完整运行、验证和重新绑定步骤见根目录 README。浏览器生成输出仍写入 `work/rigby-white/`，执行 `tools/promote-rig.mjs` 后才更新正式资源。

## 3. 已验证的现状

- 两人走近、苹果交接与入嘴消失。
- 书砸头、落地、走近、蹲下拾取、收到身后。
- 抽出扫帚、同侧并腿坐姿、飞行离场。
- 临时层次切换、物品挂点、裙摆局部变形（377 个顶点），暂停与跳转可重现。
- 原型目标 30 fps、像素比最高 2、隐藏页面暂停更新；不是完整聊天页面的性能承诺。
- 用户接受可行性基线，尚有错位及二维近似；手掌无逐指绑定，真正侧面需要补充素材。
- 本轮整理使默认苹果入口也使用白发角色；旧 `?cast=white` 链接继续兼容，`?cast=sample` 不再切换示例角色。

验证脚本：

```sh
node tools/test-rigby.mjs
node tools/test-rigby-magic.mjs
node tools/check-project.mjs
```

前两项检查真实骨骼、接触、道具状态、任意跳转确定性；裙摆额外检查 27 组参数 × 6 个过渡时刻的无翻折和上衣不变形。资源检查确认入口和模块引用存在、模型所需纹理齐全、项目模块语法有效。视觉验收仍需浏览器查看，不能由数值测试替代。

## 4. 维护注意事项

- 角色关节、裙装范围、左右图层均针对当前图校准；不能将此解释为任意角色自动绑定成功。
- `Pose.reset()` 清除局部姿态、层次及 deform，每帧重设；IK 求解后读取实际手掌挂点，防止拾物跳动。
- 侧坐时逐渐退出腿部 IK，再混合大腿、小腿和脚部角度；裙装 region 转 mesh 后用 deform，只移动腰线以下顶点。
- `writeSkeletonJson()` 返回 `{json,warnings}`，保存 `.json`；生成器用 `createImageBitmap` 与同步 PNG 编码避免隐藏浏览器的回调节流。
- 全局画布纵轴向下，骨骼坐标向上，舞台 1000×570；当前比例 0.14。改变布局先核对挂点转换。
- 程序画的书、扫帚和星形是 Canvas 图形，不需额外素材。
- `work/` 和 `local-backup/` 不属于运行依赖；禁止把资源引用指向它们，绑定生成工具的输出除外。
- 本地服务仅绑定 127.0.0.1，POST `/save` 只能写 work；不向外网暴露。服务拒绝读取隐藏目录、本地备份和原始 PSD。它是开发工具，不是生产服务器。

## 5. 下一阶段

先确定动作清单、可接受姿态、接触与遮挡规则、开始/结束/打断行为，再精细化步态、坐姿、手型与衣服变形。可优先采用手腕连续控制＋手型切换＋层次切换，不必立即逐指 IK。之后再抽象调度接口、嵌入双角色聊天布局并实测性能。

## 6. Git 与发布

远端：`https://github.com/cj2cf99/webcharacter.git`，主分支 `main`，保留原始初始化提交历史。本次为仓库同步，不部署网站，不新增自动部署工作流。实际部署前必须准备根目录 RELEASE_REVIEW.md 并取得该次明确部署许可，具体规则见 CLAUDE.md。

### 展示细节迭代

新增 `src/rigby-magic-details.mjs`：裙装网格上的褶皱明暗、坐姿压痕、魔法星屑和眩晕星星。蹲下加入裙摆压缩和外扩，坐姿加入轻微悬浮与裙摆摆动；落书增加地面回弹，台词加入反应和收纳动机。原动作测试及资源检查通过，浏览器检查了蹲下与侧坐画面。

注意：褶皱为手工指定的二维形变与明暗提示，不是布料接触求解；当前素材仍限制侧面和膝部表现。本轮未部署。

### 步态稳定性修正

魔法小剧场改为六次交替迈步：支撑期脚锁定世界坐标，摆动采用端点速度/加速度为零的五次插值，身体跟随双脚平均进度。降低重心避免膝盖反复进入完全伸直位置，脚掌保持朝向。去除无驱动力的扫帚正弦悬浮和裙摆持续波动；飞行改为加速离场，书落地采用抛物线和低回弹。

`node tools/test-gait.mjs` 实测支撑脚逐样本漂移约 1.6e-13 像素，240 Hz 采样最大脚部位移 1.37 像素；原魔法动作和资源检查通过。浏览器检查步行姿态。仍属二维编排，不等同刚体/布料物理模拟。

### 撤回锁脚步态，改为直立伪侧面小步

用户指出锁脚版本观感诡异，实际检查发现降低重心使双膝持续向同侧屈曲，身体跟随两脚平均位置导致停顿。撤回该步态及其“脚不滑即可”的验收标准。当前步行渐入骨骼小幅交替摆动，不压低重心，身体连续前进；允许伪侧面素材的滑步近似，不声称真实步行。测试改为限制膝盖弯曲和相邻采样脚部跳变，浏览器检查 4.5 与 5.4 秒姿态。原拾物和坐姿测试继续通过。

### 办公室小剧场

新增 `rigby-office.html`、`src/rigby-office-scene.mjs`、`src/rigby-office-art.mjs` 和播放控制模块。28 秒：侧边入场、拉椅子、坐下、滑到桌前、打字、报错扶额、重试成功后新需求。步行复用用户接受的小幅直立伪侧面姿态；椅背在角色后、桌面在角色前，手部由 IK 控制。无新依赖，未接大模型。

`node tools/test-office.mjs` 检查 1681 时刻骨骼有效、7 段跳转确定性及打字时手掌位于键盘区域。桌椅和屏幕为 Canvas 图形；侧面视线、手指敲击仍是二维近似。入口已加入首页。

### 组件化第一阶段

用户已确认按现有交接推进。新增 CharacterPlayer 同源 iframe 适配器、页面桥接、多实例验收页及 `docs/PLAYER_API.md`。提供 load/play/pause/seek/replay/倍速/循环/resize/destroy 和事件；资源根地址可配置。原剧场画面复用，嵌入模式隐藏原控件。

浏览器已通过实例独立控制、暂停、完成、重复创建销毁和加载失败重试。取消 RAF 和 WebGL 释放挂在子页面销毁及 pagehide；宿主移除 iframe、监听与 ResizeObserver。没有实测显存占用/回收量、真实后台及目标设备性能，因此本阶段不宣称全部性能验收完成。后续动作调度仍待开发。
