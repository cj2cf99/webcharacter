# 极乐鸟：程序化早期版（v0）

2026-11-15，在 Blender 里用纯 Python 脚本生成的极乐鸟粗模和动画节奏。**这是早期试验，建模质量被用户判定为粗糙**，模型优化已转到 [`../bird`](../bird/README.md)。这里只保留脚本，方便回看当时的做法和变身节奏。

- `build_scene.py`：生成雄鸟（身体、头、喙、眼点、腿；披肩左右两片、胸盾；四个变身阶段用链式形态键 S1–S3 表示）、雌鸟、树干、灯光和相机。运行会**清空当前 Blender 场景**。`set_stage(0..3)` 设置变身阶段。
- `animate.py`：20 秒、30 fps 的节奏：栖息 → 跳转身 → 胸盾横展 → 一下扣合成椭圆 → 原地左右快速转身 → 收拢复原；舞蹈段参考的是用户提供的 B 站视频和 GIF 的节奏（视频、GIF、渲染图和帧序列**没有上传**）。
- 用法：在 Blender 里先 `exec(build_scene.py)`，再 `exec(animate.py)`（脚本里的相机、阶段函数互相依赖，路径按本机调整）。

已知局限：材质和羽毛都是简化的；展开状态下头和身体收进披肩后，只露出两个眼点；没有真实羽毛结构。
