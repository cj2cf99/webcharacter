## 重建与输出

工作目录 `G:/selftool/WebCharacter`，使用本机已有 Blender 5.2.4（后台独立场景，不需要 MCP，也不操作已打开的 Blender）：

```powershell
& G:/blender/app/blender.exe --background --factory-startup --python-exit-code 1 --python model/mermaid/build_mermaid.py -- --views=front,side,back,beauty,face,three,swface1,swim1,swim49 --anim
```

- `--quick`：发丝降为 3/10、采样 48，用于迭代检查；`--nohair`：跳过头发。
- `--views=`：`front/side/back`（正交三视图）、`three`、`beauty`、`face`、`eye`、`mouth`、`profile`、`upper`、`upperside`、`fin`、`tailmid`、`hand`、`swimN` / `swfaceN`（第 N 帧游动姿态）。
- `--rig`：加骨架与动作；`--anim`：另渲染水下游动视频（Eevee，1280×720，96 帧 24fps 循环）。
- 输出全部在 Git 忽略目录 `work/mermaid/`：`mermaid.blend`（含骨架与 `MM_Swim` 动作）、各视图 PNG、`swim.mp4`、`build.log`。

完整构建约 5 分钟生成几何（头发最慢），渲染另计。

## 设定对照（推定值单独标注）

- 锁定尺寸直接作为几何输入：总轴长 305 cm = 82 + 140 + 83；鱼尾截面宽 39 / 32 / 20 / 13 / 9 cm；尾鳍最大展开宽 110 cm；肩宽约 35.5 cm（三角肌外缘）；单片胸衣 10.5 × 11.5 cm；眉心纹约 1 cm；耳饰垂坠约 2.5 cm；发饰扇贝约 3.5 cm、珊瑚单侧外展约 6 cm。
- **推定·非锁定**（设定 11.3 节列为待补字段）：鱼尾前后深度（约为宽度的 0.55–0.62）、鳞片尺寸与密度、各鳍叶数量 / 长度 / 角度、上半身截面与关节位置、发丝数量。这些只是本模型的建模取值，不应视为设定 V1.2。
- 姿态：采用设定 9.4 建议的标准正交建模姿态（直立、双臂 A 字外展），不是参考图的趴卧表演姿态；游动动画为俯卧水平姿态。

## 动画

`MM_Swim`：原地循环 4 秒。海豚式上下波动沿尾部逐段滞后传播（不做逐段刚体折角），尾鳍根、鳍叶、鳍尖依次延迟跟随；颈头上抬看向前方；双臂顺身体轻摆；发束三链缓慢漂动。整体以骨架对象旋转为俯卧水平。动作为程序化关键帧，不是物理模拟或动作捕捉。

## 已知限制

- 程序化建模，不是手工雕刻：脸部为几何近似加顶点着色，细微表情、皮肤毛孔级细节和真实睫毛密度有限；手指为体素重构结果，指缝较浅。
- 头发是细三棱管网格（便于蒙皮），不是 Blender 毛发曲线，近看比真实发丝粗。
- 蒙皮权重按几何计算，未逐顶点手修；大幅超出游动范围的姿态可能出现肩部、颈部挤压。
- 鳍膜与飘带依赖透明度，Eevee 视频与 Cycles 静帧的透明效果有差异。
