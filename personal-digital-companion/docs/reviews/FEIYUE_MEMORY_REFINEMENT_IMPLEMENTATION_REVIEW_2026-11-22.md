| 复核 | 发现与修正 |
| --- | --- |
| 第一轮 | 对照原话、历史引用和七天规则，补齐服务端原话、已有附件锚点和引用校验，旧记录首次成功修订只固定一次最初可用版。复核发现原记录后续追加原话可能挡住已成功的旧编号重发，改为先核对原编号和所提交文字摘要，再校验新修订的当前引用。现有表的 JSON 字段保留两版文字及最近回执，避免新云端历史表。 |
| 第二轮 | 检查分步持久和中断。长稿的复核摘要可能没有覆盖完整改动段，补齐长稿逐段复核及合稿核对。状态变动但正文和材料相同的情况下复用已复核稿，更新基线继续处理原记录。无改动任务只记本机检查结果，实际有改动才归档修订前后全文。 |
| 第三轮 | 真机 9B 首次拟稿超时，保留此前核对产物。将分段降到约 400 字并缩短提示，复测时保留原话检查挡住了未通过的稿。将原话和已有引用行标为固定文字，宿主原样拼回。小模型复测有稿件漏写备注，宿主按实际差异补记。手记核对与修订同一时刻启动有机会持续耗尽共享预算，现已错开首次轮询。 |
