## 终端管理与手动建单修订复核

来源基线 `504095b`、主站 `51c3e91`、API `d3222ca`。对照 [需求原文](../TASK_WORKSPACE.md#终端管理与取消网页手动云端执行)。

1. 区分已有浏览器关联和桌面固定 ID。电脑绑定文件只含原 ID。实际桌面走原有重启等待，先保留此前文件，再原子替换绑定。未完成的本机领取和回执仍由原任务流程收口。
2. Web 登录与同源接线覆盖 `PATCH` 改名和旧网页终端认领，主站到任务 Worker 仅转发终端关联 Cookie。别名保存后使用服务端结果。单条任务、手动任务链的浏览器创建与手动云端执行均核对服务端入口，自动登记链沿原有路径。
3. 验证桌面和窄屏终端列表，改名后两处目标设备选择、绑定文件内容、真实浏览器 Cookie 读回及仅电脑模板。首轮浏览器断言发现合成电脑模板也可使用非 `pc.` 前缀，改按服务端执行器字段核对。隐藏 Electron 实例通过托盘动作导入，第二个进程读回目标 ID 并核对备份。

实际验证包括来源全量回归、主站全量 840 项、订阅 API 33 项、两 Worker 本地 dry-run，以及既有六个桌面面板标题栏测试。无生产数据库迁移、回填或新绑定。生产授权、线上 Access 页面和实际桌面配置仍待用户验收。
