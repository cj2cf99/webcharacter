# 七日新闻编辑技能复核

2026-11-23 JST。验收依据是[用户原话和批准规则](../../REQUIREMENTS.md#七日新闻编辑与社论风向2026-11-23-jst)及[分段实现](../NEWS_BRIEFING_ARCHIVE_DESIGN.md#新闻编辑技能与社论2026-11-23-jst-开发版)。范围为工作区开发版和隔离资料。

## 真实本机模型

以用户已有的三组新闻详情和此前保存在本机的两路真实社媒回包，用 Qwen3.5-4B 逐步复跑。

| 输入 | 实际出成的标题 |
| --- | --- |
| Anthropic 挂牌 | Anthropic 挂牌首笔成交 111.50 美元，发行价 83 美元 |
| 同一话题续更 | Anthropic 次日回落，美股周末前跌势加剧 |
| 德令哈地震的铁路后续 | 德令哈地震救援暂未发现伤亡，受影响列车已限速运行 |
| 人形机器人进入手机测试工位 | 蓝思科技宣布智元 G2 部署测试工位计划 |

复核曾出现输出截断、漏掉当期市场范围、模型误判限速、机器人部署计划写成完成等问题。把当前事实与背景分开输入，复核独立入队、限制输出，增加市场范围、数值及状态的程序校验。错写多人伤亡和全面恢复的注入样本被程序拦截，即使模型的同一回包给出互相矛盾的判断。

对 16 条 X／Reddit 已保存样本实测，生成了两组名词查询和包含两站引用的同一段归纳。第一次归纳缺少引用，压缩文本并将引用约束为本期编号后重跑通过。后一轮的社论小标题把先后关系写成因果，已增加展示校验，保留合格归纳和引用。X 以帖号复核 72 小时，Reddit 原帖时间不可核时保留标记，不能支撑跨期变化。

## 行为验证

- 原本的 438 篇报道使用只读库取样，离线回播进隔离数据库。美国俄亥俄州同一枪击的两条报道合到一个节点。市场抛售主话题归入 70 篇报道、3 个节点，仍有少数泛标题或无交易时点的稿件未归并，与拟真页人工精编范围有差距。
- Node 专项覆盖自动轮询、按次使用共享 AI 队列、重启后只查剩余平台、原标题与双时间线、48／168 小时边界、归档成功才删除原记录。Python 专项覆盖 X 的 72 小时边界、Reddit 列表页排除及两站共用 70% 预算。开发版隔离 Electron IPC 核对热力块、折叠区、社媒期次懒加载、来源链接和独立滚动。
- 技能的目录路由和外置草稿检查通过，桌面构建通过。全量技能巡检仍有 privateChat 菜单路由和手记核对旧测试字段 write 两处与新闻无关的错误。
