## 范围与三项工作

1. 本地SQLite执行记录：为一个已经由可信宿主交付的任务保存本机副本与执行尝试，先落盘后执行；不改变D1作为云端任务权威源的约定。
2. 单任务执行器与唯一只读工具disk.query：固定L1、校验目标PC与参数，首次失败立即再执行一次；成功或第二次失败结束。
3. 真实SQLite、故障注入与本机只读磁盘查询验证，记录结果和未接线事项。

本组提供显式调用的Node模块，不自动领取、轮询、排队、云端回传或常驻。不接桌面生命周期与UI，不做链式关系。调用方今后负责已认证领取/交付；不能把本模块可执行视为云端授权、设备凭证和完整M1闭环已经实现。手机登记增量由子代理处理，主会话仍按约定独立审核。

## 依据与最简选择

已查阅CLAUDE与开发指南、V1.5实施计划M1-04/05/06/08、最小设计及前两组，沿用全局FRAMEWORK_PREFERENCES及独立备忘录缺失记录。保留V1.5本地SQLite先落盘要求；旧独立常驻要求服从用户最新“与精灵绑定”的决定。复用Node24内置SQLite和fs.statfs，不新增依赖、Shell执行器、插件平台或服务。

实际Node v24.22.1已确认statfs('C:/',{bigint:true})可读取本机磁盘。依据[Node24 fs文档](https://nodejs.org/download/release/v24.22.1/docs/api/fs.html)：块数乘块大小得到字节数；仅接受Windows盘符，返回JSON安全整数，不把BigInt直接序列化。

## 模块与数据

- agent/execution/disk.mjs：校验仅含drive字段且符合字母冒号；固定读取对应根目录，不允许路径、命令或用户脚本。返回{drive,total_bytes,free_bytes,available_bytes}。available为当前用户可用，free为磁盘空闲。系统平台不支持或磁盘不存在返回固定可读错误，不记录原始异常/环境数据。
- agent/execution/runner.mjs：createTaskExecutor({databasePath,deviceId,...测试用IO注入})返回execute(task)、getTask(id)、close()。应用显式提供本地路径和固定pc-ID；不在用户目录偷偷建库。
- 本地local_tasks：task_id主键、type、target_device_id、params_json、status、attempt_count、created_at、updated_at、result_json、error。这里是本机执行副本，不取代D1 tasks。
- 本地executions：execution_id主键、task_id外键、attempt_no（同任务唯一且1或2）、status、started_at、finished_at、result_json、error。无事件总线/百分比进度/上传队列表。
- 时间UTC存储，面向用户展示应使用JST。记录不包含令牌或原始系统异常。工具静态定义绑定L1；不接受任务描述自报风险或任意工具实现。

## 执行规则与示例

输入最小字段task_id、type、target_device_id、params；调用方交付前完成认证。只能执行本机目标disk.query，缺参数/其他工具/其他目标在执行前拒绝，不把请求校验失败当成两次工具执行。

首次调用保存副本。每次开始先在SQLite事务里增加已执行次数并写RUNNING执行记录，再读取磁盘；完成后同一事务保存尝试结果及任务结果。第一次工具失败时任务仍为RUNNING，保存失败尝试后立即开启第二次，不sleep、不创建第二个任务ID。第二次失败最终FAILED；成功最终COMPLETED。

同task_id再次调用：内容必须一致；已终态直接返回已保存结果，不重新执行、不清零次数。正在本进程执行时拒绝重复调用，不扩为队列。重新打开数据库时若发现未结束的RUNNING尝试，明确“执行状态待核对”，不盲目重跑；若第一次尝试已明确FAILED且尚未开始第二次，可继续仅剩的一次。完整断网对账与恢复决策留后续组，不伪造已完成。

例：任务T1查询C盘，第一次失败→本地记录attempt1失败→立即attempt2→再次失败时T1结束，次数2。以后再调用T1返回原失败，不触发第三次。另一个任务T2不依赖T1的成功；本模块不定义它们的先后或链式关系。

写操作未开放，所以不新增Paylog/提醒执行器；未来写工具必须落实幂等/回读规则，不能把两次执行理解为允许重复登记。

## 测试大纲与验收标准

| 编号 | 场景 | 标准 |
| --- | --- | --- |
| E01 | 首次成功 | 只调用一次工具，COMPLETED/次数1，任务与执行记录落盘 |
| E02 | 首次失败、第二次成功 | 顺序立即调用两次，同ID同参数，最终COMPLETED/次数2 |
| E03 | 两次失败 | FAILED/次数2，保存两次尝试，重复调用和重开后均无第三次 |
| E04 | 非法类型/参数/目标与相同ID改参数 | 执行前拒绝，不运行工具，不污染原记录 |
| E05 | 执行期间检查DB/同任务重复调用 | 调用工具前RUNNING已落盘，重复调用不增加尝试 |
| E06 | 中断恢复边界 | 未完成尝试不自动重跑；明确首次失败可继续剩余一次；不重置次数 |
| E07 | 磁盘适配 | 固定盘符路径、整数结果、失败错误无原始秘密，读数与系统一致 |
| E08 | 本机实测与回归 | 本机C盘只读查询成功，原任务/设备/终端测试继续通过 |

测试使用临时文件SQLite与注入statfs故障；本机只读检查不启动任何服务。未执行云端领取、回传、生产D1、桌面退出/重开或UI验收，需如实报告。
