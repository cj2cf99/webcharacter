# 绯月的此刻所想

## 原始需求与后续确认

绯月可以自主决定要不要看一眼屏幕，把眼前一帧作为「我老公的瞬时行为」的有限线索，再决定要不要出于探索、求知或好奇向用户提问。她天生持续对哲学有兴趣，没有具体念头时优先向哲学找突破。她也可以请本机 ComfyUI 画出自己的想法，主动分享，或直接记录念叨、日记。

用户确认专用图文弹窗每次至多两张图，只有针对具体对象的问题才加红圈。线条锐利，围在目标外围，整图理解和画作分享无圈。截图在本机压缩为 JPG。既有对话气泡遇到长文本随内容增高，默认最多展示 200 个可见字符，可展开及收起。用户要求先在本机验收交互，再决定正式发布。

## 开发实现

- 桌宠「轮询设定 → 此刻所想 · 允许自主看屏」提供开关。开发默认关闭，初始间隔 60 分钟，可复用轮询设置修改。开启后只在桌宠可见、本机有活动且没有前台对话或在途任务时参与判断。锁屏或挂起打断识图。既有手动截图问答沿用原入口。
- 本机人格模型先选择观察、思考或休息。选择观察时，取鼠标所在屏幕的单帧交给既有本机视觉模型；人格模型随后选择询问、分享或安静。是否写念叨或日记单独决定，用户实际答复单独保存。相同的最近一句想法会跳过。哲学兴趣还接入原有主动想法选择。
- 仅图片提问或分享按需要保存该帧的 JPEG；安静跳过的画面留在内存。已保留的图片与场景记录位于记忆目录对应东京日期下的「此刻所想 / 场景编号」。压缩后的同一帧用于展示、放大和坐标映射。模型选择念叨或日记时，经既有本机存储及同步入口登记文字。图像保存在本机。
- 对明确颜色的单个目标先测连续像素边界，其他细节由视觉模型提供归一化外框，再核对裁剪区域。坐标越界、模糊或核对失败即省去标注。红圈在独立矢量层绘制；放大图片后一起缩放。生成图使用既有 ComfyUI 作业和持久回执，完成后在空闲时展示。截图和成图合计两张。
- 复用月印标题栏、现有轮询设置、对话气泡、本机记忆和图像工作流。查阅了项目及父仓库开发指南、桌宠界面开发说明、截图问答设计、人格记忆约定、任务模板设计中的备忘索引，以及全局 FRAMEWORK_PREFERENCES.md。
- 桌宠子项目的记忆 API 和手记阅读器增加 curiosity 念叨来源；沿用已有字段与表，数据库 DDL 无。将来发布需同步新版来源校验至实际承载记忆 API 的服务。

## 本机验收

从桌宠子项目根目录运行 `node tools/scene-preview.mjs 18766`，浏览器打开 `http://127.0.0.1:18766/`。入口使用实际桌宠页面和合成场景，回复仅用于页面试用。样例包括单图、双图、整图、画作和可展开的长回复。开发机本轮的 ComfyUI 实际成图在 `output/scene-qa/letter.png`，缺少该样例时预览使用合成插画。真实截取用户桌面和向生产服务写入均未用于验收。

2026-11-21 JST 的验证结果：

- 人格、记忆、轮询开关、问答宿主、绘图和新场景相关的七个 Node 测试文件共 71 项通过。隔离 SQLite 核对了日记草稿、念叨来源、答复归属和幂等重试。
- `tools/test-scene-preview-electron.mjs` 用 375、768、1040 像素窗口操作实际页面，验证每次最多两张、整图无圈、放大返回、回复、窄窗按钮可达、收起以及 200 字折叠。
- `tools/test-scene-native-electron.mjs --vision` 验证真实 Electron 弹窗、IPC 和本机视觉模型。合成双色图上，红圆实测外框为千分比 [675,206,138,220]，裁剪图由视觉模型确认。单靠小模型生成的坐标在该例有偏差，已加入像素边界和裁剪复核。复杂桌面上的定位精度仍需实际使用验证。
- 同一工具使用 `--initiative` 和合成资料运行了真正的本机人格模型，一次实际选择为观察、提问和绘图。另用隔离图像作业从 ComfyUI 得到 512 × 512 的 PNG 并在预览中展示。
- `node tools/build-desktop.mjs`、项目标题栏 Electron 测试、真实气泡测试通过。用户本地交互验收待反馈。当前是开发候选。

2026-11-21 JST，用户在收到本地交互验收入口和实测结果后回复「可以」，本地界面方案已获认可。逐项手动操作结果未单独反馈。
