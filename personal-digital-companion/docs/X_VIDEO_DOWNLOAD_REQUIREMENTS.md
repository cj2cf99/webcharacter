## 2. 目标与范围

单人自用。由绯月桌面端在本机代行调用 `yt-dlp` 下载 X（Twitter）视频并结合内置隐藏窗口抓取保存 X 长文/帖子及内嵌媒体，集中保存在 `F:\Xdownload`（根目录维护便携索引 `catalog.json` 支持搬迁与自动同步），支持本地最大并行 3 个任务（文章最多占 1 路）、实时进度展示、超时自动暂停并降至最低优先级后继续调度队列其他任务、完成在既有提醒体系内提供「缩略图 + 播放/打开键」直呼本地默认程序、以及仅归档不删除的内容管理；并配套本地 Chrome 插件提取 X 登录 Cookie（点击复制后粘贴导入绯月）。同时在底层下载接口与插件结构上预留后续「云端任务下发」与「一键生成云端下载任务」扩展点。

## 4. 与框架默认的差异

按本次需求：视频文件、文章目录、目录索引 `catalog.json`、缩略图缓存、队列状态与加密 Cookie 均保存在本机，不走主站 D1/KV 和 GitHub 图库；不设分类、Tag、父子层级，管理界面不提供删除功能（仅提供归档）。

## 5. 不包含（最简化边界）

云端任务下发的服务端与云端页面、Chrome 插件一键生成云端下载任务的实际提交实现、本期改动 `desktop/local-rest.mjs`（8765 本机接口）、任何删除磁盘视频/文章的操作、管理界面重命名、Playwright 或外部 Chrome 挂接、文章目录内重复 `meta.json` 或 `media/` 子目录、向上追溯祖先贴、绕过验证码/风控、在抓取脚本内内置大模型、用户手工配置多级优先级（仅系统内部两档：普通 / 超时降级最低）、自定义本地播放器/阅读器路径配置、自定义代理设置页、X 以外平台的专门适配、视频转码/剪辑/画质手选界面。

## 6. 验收要点

1. 右键菜单「本地复盘」正下方可见「X视频下载与管理」入口，轻量「登记下载」小窗与「X视频管理」窗口可各自独立打开，关窗后后台下载继续。
2. 省略名称时按 JST 精确到秒自动命名，重名自动加序号不覆盖；多视频帖子自动编号并全部入管理列表；同链接在途不重复占槽。
3. 未配 `yt-dlp.exe` 时明确报错指引；每天最多自动检查一次更新，手动「检查更新」可用；发现更新必须经用户同意才更新，且不与在途下载撞文件锁。
4. 本地支持最大并行 3 个下载任务，实时显示进度；超 1 小时未完成自动暂停（保留断点于独立临时目录）、降至最低优先级、发超时提醒并继续处理其他队列任务；点击继续不抢占普通任务且重计 1 小时；重启不丢断点队列。
