# 窗口边缘电梯上行（2026-11-18 JST）

三份原视频保存在 source/。manifest.json 记录源文件、哈希、帧数和定位数据。24 fps，画幅 464×688。去掉绿幕和原音轨，保留人物、法阵及光效。

| 文件 | 动作 | 源帧区间（零起点） |
| --- | --- | --- |
| enter.webm | 进入电梯 | [0,145) |
| run.webm | 电梯运行，可循环 | [0,38) |
| exit.webm | 离开电梯 | [0,145) |

运行窗口约 1.58 秒，保留一次明显的光效脉冲。以运行首帧作为共同接口，片段边缘在六帧内做预乘透明度融合。入→运行、运行→运行、运行→离开三处解码帧逐像素相同。

重建用已有 Python/numpy 与 FFmpeg 执行 tools/prepare-elevator.py。桌宠构建只复制三份 WebM，源视频和元数据保留在项目内。
