## 从桌面测试服务端 AI

打开「设置与维护 → 云端连接 → AI 轮询测试」。绯月会请服务端按当前接口顺序发送带东京年月日时分秒的问候。第一家返回有效模型文本就停止，显示成功、接口名和模型。问候和时间一致时还会显示模型原话；不符时在当天的任务通信日志记录 `reply_check: mismatch`。手动检查按服务端顺序进行，可能使用收费接口。自动轮询优先使用一小时内上次选中的可用接口，每个新请求都可以重试上一轮失败的接口。

全部接口都尝试失败时，弹窗列出本次实际尝试的接口。如果连接中断或服务端版本还没有这个入口，弹窗显示未取得完整结果。各接口的错误码、上游状态码（如有）和耗时保存在对应东京日期的 `F:\feiyuememory\YYYY\YYYY-MM\YYYY-MM-DD\日志\任务通信.jsonl`。

每个接口的最近一次拒绝可按接口名和时间在日志中查找。菜单、心跳和登记使用任务通信日志；普通问答保存到该次对话的失败记录。字段 `refusal_response` 保存供应商实际返回的脱敏文本，最多保留前 2048 个字符并标记截断。连接超时等没有正文的故障只记错误码。

## 轮询设定

## 环境与候选判断

- 本机已有Node.js 24、npm、WebView2 Runtime；dotnet仅运行时，没有SDK；未找到Electron、cargo或rustc。

- 用Electron的DIP鼠标坐标每50ms通知渲染器，Canvas实际Alpha判定人物区域后回报穿透开关；窗口外自动穿透。该机制仍需Win11/DPI/实际鼠标时序验证，不承诺逐像素无延迟。
- 托盘提供显示/隐藏、开始/结束工作、回到右下角、退出；隐藏暂停视频及位置轮询，退出清理IPC和托盘。
- 共享四状态完全复用当前v3素材，工作来源仍为工作三段2；动画细节不调整。
- `preload.cjs`：隔离暴露命中/就绪/事件订阅，不暴露Node或任意IPC；宿主校验消息来源主frame及布尔值。
- 本地资源运行，渲染器拒绝外联请求、远程导航、新窗口和权限请求。登录启动项由用户通过「设置与维护」勾选或取消。
- `build-desktop.mjs`准备本地包，`run-desktop.mjs`只检测并启动已安装的Electron，绝不会自动安装；清除继承的ELECTRON_RUN_AS_NODE，避免以Node模式误启。

## 用文字修改提醒

在「问绯月」里输入“查询明天的提醒”“把周报移动到明天”或“把周报的时间改为下午三点”。点击气泡中的「待确认」，有多个匹配时先勾选一个或多个，点击「查看修改方案」。核对每项的原值和目标值后，可一次同意或放弃整组。查看清单后也可以关闭窗口，在气泡里回复“我同意”或“我不同意”。清单变化后须重新查看。

可以直接关闭窗口继续做别的事，从气泡或本地复盘再次进入「待确认」。本机加密保存选择和方案，各自从提出时起最多保留一小时。更新结果可在当天对话记录中查看。

## 绯月的情境动作

启动时绯月先挥手。退出时会显示绯月，等鞠躬收势才关闭；有运行中任务时，仍先询问是否退出。本地开发版重新启动后会载入这批动作。

| 场景 | 动作 |
| --- | --- |
| 普通特殊待机到点 | 从现有设置里的特殊待机和《闲置特殊2》各以一半概率选一次，允许连续抽到同一段。 |
| 「提醒」有未读 | 闲置时举铃，未读期间后续特殊待机也选举铃。 |
| 写日记或补行动评价期间 | 循环沉思，任务结束或中断后恢复当前状态。 |
| 气泡聊天识别为登记 | 播放《对话时接到了任务》。登记确认继续使用原流程。 |
| 本地执行其他任务 | 使用现有工作动画。任务开始时会退出自动漫游或原有窗口依附。 |
| 东京时间 21:00 后检查每日学习 | 当天多邻国提醒和长期任务均已完成，当前普通闲置才播放《亲爱的真棒》。同一天只核对发奖一次，忙时跳过。 |

晚间核对依赖提醒服务返回当天的双完成标记。可在设置的动画资源库预览这七段素材。
