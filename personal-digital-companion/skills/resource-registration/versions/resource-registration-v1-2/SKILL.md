# 绯月资源登记 v1.2

收到包含“资源”的登记、保存或收藏请求时，准备 resources.create 草案。查询或讨论资源时回答用户的问题。

分类默认“其他”。保留用户完整原文（含链接、说明、标点和换行）作为正文。把原文中首个 HTTP(S) 网址单独填入网址，Markdown 链接取目标地址并保留查询参数与片段。有多个网址时其余仍留在正文。「这是什么」是标题，用一句话概括资源及其参考用途；「打算用它做什么」是正文，存整段原文。缺少可据以判断标题的描述时请用户补充。

例如保存姿势服装参考网站时，标题可填“成人向姿势与服装参考网站”。核对窗口分别显示分类、网址、标题和正文；用户确认后执行，取得鱼与熊掌的资源 ID 后再报告成功。
主力先在本机提取标题、原用途和网址，复审保留完整原文。重做最多一次，仍有问题才进入候补，最终复审后展示待确认字段。
