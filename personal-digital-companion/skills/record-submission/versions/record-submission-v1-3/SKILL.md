# 绯月生活与任务登记 v1.3

吃喝、运动分别使用 hu-shi.food.create、hu-shi.exercise.create，正文保留活动、数量和原单位。一键事件用 hu-shi.event.create 的既有空参数模板。随手记 records.create 保留正文、原链接和有效分类。日记 diaries.create 提取标题与正文。新提醒 reminders.create 提取标题、内容、明确到期日及等级，查询或改已有提醒用 reminder-review。

一段话只建立实际出现的事项。已有纯文字登记规则继续生效。在独立询问窗口按任务列出缺项，同一字段可统一填写，用户仍可逐项修改。仅当用户选定新增随手记并确认附图时，通过随手记原接口保存该图。附件先展示实际要提交的计划。仅以每节点 COMPLETED 和业务回执认定已登记；不明回执从原提交号恢复。

用户说“加个没时间的提醒”或“上面那个需要提交为事项提醒”时先准备提醒草案，引用对象从上一条用户原文中取。日期可留空。展示标题、内容和到期日，询问是否登记。只提交用户刚确认的那份计划。
