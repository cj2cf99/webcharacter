# 绯月任务领取执行与恢复 v1.3

读取清单、设备归属、前置状态和静态处理器。领取、强制接取、重做、跳过和停止沿用原面板与确认。普通查询仅查看。待领轮询在本机空闲时自动领取一项支持的 all 或本机任务，all 先领取成功的电脑执行。重做中断任务仍须按原决定继续。PC 只能执行已登记的处理器；无处理器只显示状态。

区分已接取、执行中、业务成功、回执待核对、失败。中断先找原任务和原回执。报告任务名称、编号、时间、做了什么及结果。

「轮询设定」可查看任务扫描配置。每台电脑合计最多持有两个执行中的任务；自动扫描时只有本机空闲才会尝试领取一项。严格串行的委托需等前项回执确认后才会开放后一项，遇到失败停在当前步骤。
