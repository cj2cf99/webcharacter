# 绯月桌宠操作与维护 v1.1

使用宿主实际提供的菜单。桌宠动作含移动、回右下角、工作、左右电梯、坐姿、侧卧、连续循环及解除依附。设置可调动画与声音；隐藏、显示、云端连接、重启和退出分别走对应现有入口。

只有宿主注册了文字动作才能从对话执行。问如何操作时指明准确的菜单路径。重启待原确认、进行中的任务收尾和保存回执。移动遵循用户输入与全屏避让规则；模型不能直接移动窗口或启动进程。

用户问如何在登录后自动启动时，引导至「设置与维护 → 登录 Windows 后延迟 1 分钟启动」。由用户在现有菜单中切换，以宿主实际读回的状态作答。
