# 华丽极乐鸟 · 单页 2D 形态与动作试验

日期：2026-11-16，Asia/Tokyo。独立目录，不改 3D 模型、不含母鸟、不接主站、不部署。

**当前版本：32 秒连续求偶舞，固定母鸟观看机位，雄鸟面向镜头并沿树干明显左右挪步。** 已移除四态按钮及等时轮播；四个旧参数端点只作为内部羽毛开合参考，不限制动作。支持暂停、进度拖动、重播、循环和倍速。

## 用户原始需求

> 你现在试着用2d方式实现华丽极乐鸟的三种舞姿和平时状态的切换切换动画，先不考虑母鸟，我想看看2d实现的程度和3d能差多少，单网页的2d化极乐鸟舞姿展示，场景还是一跟树干的局部场景

后续明确要求：

> 请循环迭代到你认为和真实形象和动作有90%还原的程度
>
> 继续，你在自己内部浏览器上确认
>
> 我没动，并且允许你使用和截图自己的内部浏览器

本轮后续明确变更：

> 取消四个基础动作的限制，你尽量还原极乐鸟的求偶舞蹈就好
>
> 另外让镜头成为母鸟代替品，以这个角度去安排舞蹈
>
> 雄鸟何以左右移动，但是不能跳出视野之外
>
> 允许在实际界面上出现横向位移，不必固定在中央

最后两条按“可以左右移动，实际画面不必居中，但雄鸟不能出画”落实。没有增加母鸟，镜头是展示对象。以下早期四态来源保留，当前范围以上述变更为准。

本轮按用户直接实现及持续迭代的明确指令进行。90% 是质量目标，不是已测得的相似度；没有逐帧标注、同视角对应与统一评分标准，不能宣称客观达到 90%。最终外观仍待用户确认。

## 范围、依据与验收

- 连续过程：观察镜头、俯身亮冠、胸盾试探、掀起/扣合披肩、转向短跳、沿树干挪步、落地停拍、再次展示、松开收羽及停歇。32 秒为代理编排长度，不是用户规定或完整自然求偶时长。
- 固定母鸟机位，主要朝镜头展开；左右落脚点沿树干实际移动（路径约 ±85 个局部画布单位，加短跳侧移），不通过追踪相机把鸟锁回中央，桌面/手机均保留展开和跳起余量。
- 开合、呼吸、俯首及跳步为程序化近似，不冒充真实动作捕捉。
- 一只雄鸟、一段树干和林下背景；不加入母鸟、交配交互、音效、账户或存储。
- 常态具有鸟体、短颈、窄喙、贴体胸羽和叠压折翼；展开态是吸光黑色椭圆披肩、蓝绿胸盾和冠羽形成的亮点，真实眼睛与鸟体应遮蔽。
- 动作参考仓库已有 `work/bird-blender/ref/dance.gif`（真实拍摄的展开/转向/弹跳），不将该临时路径作为运行依赖；旧粗模动作仅供查找四阶段定义，不能作为真实生物学依据。
- 用户原参考 `model/bird/reference/turnaround-20261115.png`、`animation-breakdown-20261115.png` 仅用于形体/分区核对，未将其作为直接运行贴图发布。
- 外部依据：[Australian Museum](https://australian.museum/about/history/exhibitions/birds-of-paradise/superb-bird-of-paradise/) 的黑羽、蓝胸盾、后颈披肩、蹲伏和跳动描述；[Cornell](https://news.cornell.edu/stories/2018/04/smooth-dance-moves-confirm-new-bird-paradise-species) 区分 greater superb 的椭圆/弹跳与 Vogelkop 的新月/滑行，避免混用。
- 固定视角的二维近似，不等同任意视角 3D、物理羽毛求解或物种级动作捕捉。没有母鸟时只演示原地展示节奏，不虚构绕母鸟的交互。

## 设计与最简约束

已查 `CLAUDE.md`、`docs/DEVELOPMENT.md`、原 `REQUIREMENTS.md`、`docs/DESIGN.md`、文档索引和 `G:/selftool/resourceforlater/docs/FRAMEWORK_PREFERENCES.md` 的最简、少文字和不委派要求。沿用原设计对独立全局/项目备忘录未找到的记录；此次再次查文档索引，未新增独立备忘录，不虚构已查阅。

原生 Canvas 2D 与 ES Modules，无新增 npm 依赖和构建。`courtship.mjs` 负责连续编排；`bird-art.mjs` 负责分层绘画；`motion.mjs` 负责短跳与挪步；`reference-turns.mjs` 保存真实 GIF 第 16–64 帧提取的胸盾倾角/相对宽度（10 fps、三帧平滑，4.8 秒后附 0.6 秒衔接）。仅用它校准倾角和宽度；胸盾平移受视角、阈值和遮挡影响，未直接套到身体或脚上。

`main.mjs` 负责背景和播放。静态背景预绘一次；首屏仅加载必要模块及两张 PNG（合计 3,123,012 字节）；暂停/隐藏时停止动画帧。没有长列表或历史数据，不引入懒加载框架。生成图、SHA-256 与完整提示词见 [assets/SOURCES.md](assets/SOURCES.md)。

生成贴图为二维素材，由同一 Canvas 动作控制器驱动；不是 3D 渲染帧序列。素材来源与生成说明另存同目录。失败时保留程序绘制回退和重试状态，不让页面空白。

数据库、数据回填、KV、API、服务端配置、生产影响：无。没有 Cloudflare Worker，不涉及 Worker 部署验收；本地由已有静态开发服务运行。
